## Serving

### `serveLcpStdio(ports, options?)`

Serve over stdio — what every desktop agent host speaks. Returns the SDK's `StdioServerHandle`; `options`
is the SDK's `ServeStdioOptions`, passed straight through, which is the door a linked in-memory transport
or a socket-bound deployment goes through. Both types come from `@modelcontextprotocol/server/stdio`.

### `createLcpMcpServer(ports)`

Build an `McpServer` and connect any transport yourself. A **factory**, not a singleton: transports may
build one instance per connection, and a shared instance would make one client's state another's.

### `nodePorts(env)`

The Node wiring — the real guarded fetcher, plus `LCP_MCP_REVERSE_DOMAIN` if the environment states one.

### `isoNow()`

The wall clock as an ISO-8601 instant.

### `REVERSE_DOMAIN_ENV`

The environment variable name a deployment states its reverse-domain namespace in.

### `LcpMcpPorts`

`{ fetcher, deployment? }` — no defaults. See [ports](/mcp#ports).

## Dispatch helpers

### `resolveAdapter(protocol, ports)`

Turns a wire token into a placement adapter, through `@integraledger/lcp-placements` and nothing else.
Takes the whole `LcpMcpPorts` — the namespaced placements read `deployment` off it — and it is required.

Two failures, kept distinct: a token that is not an LCP protocol id throws naming the closed set, while a
real protocol id with no registered placement throws naming what this build *can* place into.

### `manifestSummary(manifest)`

The manifest facts a caller needs to see where a reference went, without shipping the manifest's own prose
and alias table. `container` reports the kind only; the human-readable locator is `field`.

### `refusalResult(refusal)`

A placement `Refusal` — the value type from `@integraledger/lcp-binding-core`, never a string — as MCP
sees it. The halt class and the stable code travel in `structuredContent` where a caller can branch on
them, and `isError: true` is what makes MCP hand the whole thing to the model.

## Discovery

### `legalContextUrl(serviceUrl)`

Normalizes a service origin to its well-known legal-context URL. A query string, a fragment, or
credentials in the authority are **refused** — §2.1 defines the well-known URI with none of them.
