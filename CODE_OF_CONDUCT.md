# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
as its code of conduct. It applies to everyone who takes part in the project, in every project space: issues, pull
requests, discussions, and any other channel where the project is represented.

In short: be respectful and welcoming, give and accept constructive feedback, and focus on what is best for the
community. Harassment, personal attacks, and publishing others' private information are not acceptable.

## Reporting

Report unacceptable behaviour to the project maintainers at
[opensource@integraledger.com](mailto:opensource@integraledger.com). Every report is reviewed and handled in
confidence, and the maintainers respect the privacy and safety of the person who reports.

Report a security vulnerability only through GitHub's private vulnerability reporting, as [SECURITY.md](./SECURITY.md)
describes, never to this address.

## Enforcement

The maintainers enforce the code of conduct following the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, and permanent ban, according to the impact of the behaviour.
